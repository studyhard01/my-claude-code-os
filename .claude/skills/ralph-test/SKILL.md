# Ralph Test — 테스트 채우기 루프 (한 호출 = 한 바퀴)

이 스킬 **한 번 호출은 "한 바퀴"** 다: 테스트 없는 모듈 **하나**를 골라 테스트를 쓰고, 통과를 확인하고, 커밋하고, 진행 상태를 기록한다. **반복은 `/loop /ralph-test` 가 담당**한다 — 이 스킬 안에서 여러 모듈을 처리하려 들지 말 것.

랄프 루프의 전제: 매 바퀴는 이전 바퀴의 대화를 기억하지 못할 수 있다. 그래서 "어디까지 했는가"는 머리가 아니라 **진행 상태 파일**(`.claude/ralph-test-progress.md`)에만 의존한다.

## 한 바퀴 절차

1. **진행 상태 읽기** — `.claude/ralph-test-progress.md` 를 읽는다.
   - 파일이 없으면(첫 바퀴) `src/`·`scripts/` 를 스캔해 아래 "대상 선정 기준"으로 목록을 만들어 파일을 생성하고, 이번 바퀴는 거기서 시작한다.
   - `tests/` 실제 파일과 대조해 체크 표시가 어긋나 있으면 파일 기준으로 바로잡는다(파일이 진실).

2. **종료 판정 (먼저!)** — 미완료(`- [ ]`) 항목이 하나도 없으면:
   - "ralph-test 완료 — 모든 대상 모듈에 테스트 존재"를 보고하고,
   - `/loop` 로 돌고 있다면 **루프를 멈춘다**(dynamic loop 이면 `ScheduleWakeup` 에 `stop: true`).
   - 여기서 끝. 새 일을 만들어내지 말 것.

3. **하나만 고른다** — 미완료 항목 중 **가장 위**(우선순위순) 하나. ⛔ 메모에 "건너뜀" 사유가 적힌 항목은 지나친다.

4. **테스트 작성** — `tests/` 아래에 `src/` 구조를 미러링해 만든다(예: `src/lib/format.ts` → `tests/lib/format.test.ts`).
   - 정상 케이스 + **경계 케이스**(null/undefined, 빈 문자열, 매핑 실패 등)를 반드시 포함.
   - 계약 관련 모듈은 **OS.md 12장이 기대 동작의 기준**이다. 테스트는 "현재 코드가 하는 일"이 아니라 "계약이 요구하는 일"을 검증한다.
   - import 는 `@/...` 별칭 사용(vitest.config.ts 에 설정됨).

5. **기계 검증 — 통과 없이는 커밋 금지**
   - `npm test` 와 `npm run typecheck` 둘 다 통과해야 한다.
   - 테스트가 실패하면: 먼저 **테스트가 틀렸는지** 의심하고 고친다.
   - **소스 코드의 버그로 판명**되면: OS.md 12장 계약에 비추어 **명백한** 버그일 때만 소스를 고치고, 커밋 메시지에 "버그 수정 포함"을 명시한다. 계약 해석이 갈리는 사안이면 소스를 건드리지 말고 진행 상태 파일 ⛔ 메모에 기록한 뒤 그 부분 테스트는 제외하고 보고한다(계약 변경은 기획자 권한).

6. **커밋 + 기록** — 진행 상태 파일의 해당 항목을 `- [x]` 로 바꾸고 테스트 파일과 함께 커밋한다.
   - 커밋 메시지 예: `normalizer 테스트 추가 (ralph-test)`
   - 마지막으로 이번 바퀴 결과(모듈명, 테스트 수, 남은 항목 수)를 한 문단으로 보고한다.

## 대상 선정 기준 (첫 바퀴 목록 생성 시)

- **포함, 우선순위순**: ① 순수 로직(수집 Normalizer, 직렬화, 포매팅) ② 의존성 주입으로 격리 가능한 것(fetchFn 주입 어댑터 등) ③ fetch/DB 목킹이 필요한 것(API 클라이언트, 라우트 핸들러).
- **제외**: React 컴포넌트·페이지(`.tsx` UI — 별도 도구가 필요해 이 루프 범위 밖), 타입 선언만 있는 파일, Prisma client 래퍼(`db.ts`).
- DB(Prisma)가 필요한 항목은 목록 맨 뒤에 두고, 실 `prisma/dev.db` 를 건드리지 않는 방법이 없으면 ⛔ 메모에 사유를 적고 건너뛴다.

## 규칙 요약 (안전장치)

- **한 바퀴 = 한 모듈.** 여러 개가 쉬워 보여도 하나만.
- **초록불 없이 커밋 금지.** `npm test` + `npm run typecheck`.
- **진행 상태는 파일이 진실.** 바퀴가 끝나면 반드시 갱신하고 커밋에 포함.
- **소스 수정은 예외적.** 기본은 테스트만 추가. 수정 시 커밋 메시지에 명시.
- **끝나면 스스로 멈춘다.** 종료 조건 충족 시 루프 정지 선언, 대상 목록을 임의로 늘리지 않는다.
