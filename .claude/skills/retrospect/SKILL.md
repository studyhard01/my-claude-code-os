# Retrospect — 세션 회고: 배움을 LESSONS.md 에 누적

세션(특히 루프)이 돌 때마다 이슈가 생기고 해결되지만, **기록하지 않은 배움은 다음 세션이 같은 시행착오로 다시 산다.**
이 스킬은 세션 끝에 그 배움을 수확해 `LESSONS.md`(저장소 루트)에 쌓는다. ralph-test 의 📚 절이
"그 루프 전용"이라면, LESSONS.md 는 **모든 루프·세션을 관통하는 일반 교훈**의 집이다.

## 절차

1. **증거 수집** — 이번 세션에서 실제로 벌어진 일을 모은다.
   - 대화에서: 실패했던 명령·잘못된 짐작·막혔던 지점, 그리고 그것을 어떻게 개선/해결했는지.
   - 보조 자료: 이번 세션의 커밋들(`git log --oneline`), `.claude/ralph-test-progress.md` 의 ⛔·📚 신규 항목.

2. **교훈 추출 — "다음 세션의 행동을 바꾸는 지식"만.**
   - 형식: `이슈 상황 → 확인된 개선책` 이 한 줄에 드러나게.
   - **안 적는 것**: 일반 상식, "잘하자"류 다짐, 이 세션에만 유효한 일회성 세부사항, 이미 CLAUDE.md·LESSONS.md 에 있는 것.
   - 이미 있는 교훈과 겹치면 새로 추가하지 말고 **기존 항목을 보강하고 날짜를 갱신**한다.
   - 한 세션에 **최대 5줄** — 수확이 없으면 0줄도 정상이다. 채우기용 기록은 읽는 비용만 늘린다.

3. **LESSONS.md 에 누적** — `## YYYY-MM-DD (세션 주제 한 마디)` 헤딩 아래 항목을 append 한다.
   파일이 없으면 헤더(기록 규칙 포함)부터 생성한다.

4. **승격 제안 — 교훈에도 갈 곳이 있다.** 옮겨 적지 말고 제안만 한다(중복 기록 금지).
   - **모든 세션·에이전트가 항상 알아야 함** → `CLAUDE.md` 승격 제안 (사용자 승인 후 이동, LESSONS.md 에서는 삭제).
   - 계약 관련 → `OS.md 12장` (기획자 권한 — 사용자에게 회부).
   - 루프 구조가 바뀐 것 → 루프 지도(`docs/dev-loop-map.html`) 변경 이력 (loop-map-context 훅이 별도 촉구).

5. **보고** — 남긴 교훈 수 · 보강한 항목 수 · 승격 제안 목록을 한 문단으로.

## 원칙

- **LESSONS.md 는 append 위주** — 과거 교훈을 지우는 건 틀렸음이 판명됐을 때뿐(그때는 지우고 이유를 커밋 메시지에).
- 이 파일이 커지면 읽는 비용이 배움의 가치를 넘어선다 — 그래서 2단계 기준(행동을 바꾸는가)과 4단계 승격(항상 필요한 건 CLAUDE.md 로)이 안전판이다.
- 커밋은 세션의 다른 변경과 함께 /commit 으로(검증 게이트 적용, 문서-only 면 게이트 생략 가능).
